# Support matrix

| Area | Supported baseline |
|---|---|
| Python | 3.10–3.12; CI validates all three |
| Operating systems | Ubuntu, macOS and Windows in CI |
| Clients | Codex, Claude Code, Cursor, VS Code/Copilot, OpenCode and compatible `SKILL.md` loaders |
| Optional tools | Pandoc, XeLaTeX/pdfLaTeX and competition-specific solvers are detected, not bundled |

The skill is a workflow and evidence gate, not a guarantee of a winning model
or of a particular competition's current rules. When reporting a bug, include
the public version, client, Python version, command, a sanitized synthetic
fixture and the smallest relevant log. Do not attach papers, credentials,
private datasets or unredacted team workspaces.
