# Maintainer and reproducibility docs

The root README is the user-facing landing page. These pages collect the
operational details needed to maintain a trustworthy public skill:

| Page | Purpose |
|---|---|
| [Development](./development.md) | locked setup, tests, lint and local release gate |
| [Agent evaluations](./evaluations.md) | contract cases and recorded-run validation |
| [Release](./release.md) | tag, archive, checksum, SBOM and attestation flow |
| [Support](./support.md) | compatibility and what to include in a bug report |

The public repository intentionally remains usable without a docs site or
external service. Every command below is also runnable from a clean checkout.
