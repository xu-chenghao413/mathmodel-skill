# Security policy

Do not publish vulnerabilities that expose private contest data, credentials or unpublished manuscripts in a public issue.

For ordinary bugs, open a GitHub issue with a minimal synthetic reproduction. Remove team names, school names, contest identifiers, tokens, local paths and source documents before posting.

For a sensitive report, contact the repository owner privately through the contact method listed on the GitHub profile. Include the affected version, impact and a reproduction that does not contain third-party or user-confidential material.
