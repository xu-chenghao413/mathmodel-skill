# 论文资料（默认不公开）

论文 PDF、OCR 文本、截图和下载报告不属于本 skill 的运行时输入，也不应提交到 Git 仓库。若维护者需要更新 `competitions/cumcm/empirical.json`，请在仓库外的私有目录中使用拥有合法访问权限的资料，完成来源、许可、转换和人工复核记录后，只把聚合字段和独立撰写的结论带回仓库。

公开仓库不提供自动下载器，也不承诺任何来源允许再分发。官方规则和论文链接只作为外部来源记录，具体条款由来源方决定。

## 私有维护流程

1. 将有权使用的本地 PDF 放在仓库外的临时目录；
2. 用 `scripts/ingest_papers.py` 生成统计草稿；
3. 删除或隔离源文件、提取文本、文件名中可能包含的身份信息；
4. 在 `PROVENANCE.md` 补齐 URL/权限、访问日期、样本量、转换方式和复核人；
5. 只提交不含原文、个人信息和可识别案例的聚合统计。
