# Governance

`mathmodel-skill` is currently maintained by `xu-chenghao413`. A single
maintainer may review and merge pull requests; contributors are credited by
their Git history and release notes when they choose to identify themselves.

The maintainer owns release/version decisions, provenance and security
triage. Changes that alter state schemas, delivery gates, licensing or public
installation paths require tests and a changelog entry. Community proposals
are welcome through issues and pull requests; GitHub branch protection remains
the final merge control.

This document describes repository process, not legal authorship. File-level
notices and [`THIRD_PARTY_NOTICES.md`](./THIRD_PARTY_NOTICES.md) continue to
control historical or third-party portions.
